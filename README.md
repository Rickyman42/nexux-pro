# Nexux Pro

Landing page de **nexux.pro** — asistentes de IA para peluquerías y centros de estética.

Stack: Astro 6 + Tailwind 4 + Vanilla JS bot widget.
Deploy: Vercel (static).
Leads: Microservicio Node.js en la Pi (nexux-pro-leads, PM2).

## Desarrollo
```
pnpm install
pnpm dev   # http://localhost:4325
```

## Build
```
pnpm build
```
